# BLACKFORGE

Independent development studio portfolio by se1dhe.

**Live:** https://se1dhe.github.io/blackforge/

Buildless HTML, CSS and JavaScript. Self-hosted fonts, Ukrainian / English / Russian, filterable case studies, accessible native dialogs, image viewer, deep links and Telegram project briefs. No analytics, trackers or form backend.

## Preview

Run `python3 -m http.server 8640` in this directory.

## Content

Case study and localization data: `app.js`. All product screenshots are from the author's projects. ForcePlay inventory is demo data. FLEUR does not process real payments in its demo.

The brief opens a user-reviewed draft in Telegram; the website does not transmit a form to a server or store it.

## Deployment

GitHub Pages publishes the repository root from `main`. All paths are relative so deployment works under `/blackforge/`.
